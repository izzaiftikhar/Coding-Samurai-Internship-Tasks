# Python Calendar Generator

A beginner-friendly Python mini-project that generates a formatted calendar for any month and year.

## Features
- Displays today's date
- Accepts year and month input
- Validates month values (1–12)
- Generates a formatted monthly calendar

## Technologies
- Python
- `calendar` and `datetime` modules

## How to Run
```bash
python calendar_generator.py
```

## Concepts Practiced
Functions, variables, user input, type conversion, conditionals, input validation, and Python's standard library.
