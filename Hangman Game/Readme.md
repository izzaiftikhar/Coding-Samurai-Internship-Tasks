# Hangman Game

A simple text-based Hangman game built using Python.
The player has to guess a hidden word by entering one letter at a time. For every incorrect guess, the number of remaining attempts decreases. The goal is to guess the complete word before running out of attempts.

This project is designed as a beginner-friendly Python project to practice programming fundamentals such as loops, conditions, functions, lists, and user input handling.

# Features:

- Random word selection from a predefined word list
- Letter-by-letter guessing system
- Maximum of 6 incorrect guesses allowed
- Displays the current progress of the hidden word
- Tracks previously guessed letters
- Prevents duplicate guesses
- Provides win and game-over messages
- Simple console-based gameplay with no external libraries required

# Technologies Used:

- Python 3
- Random module

# Concepts Practiced:

- Variables and data types
- Lists and list operations
- Loops (`while` and `for`)
- Conditional statements (`if-else`)
- Functions
- Importing and using modules
- String manipulation
- User input handling
- Basic game logic
