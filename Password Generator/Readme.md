# Password Generator

A simple Python project that generates random passwords using letters, numbers, and special characters.

## Project Overview

Users can choose a password length to generate a random password with a minimum of 8 characters.

## Features

- Generates random passwords
- Includes uppercase and lowercase letters
- Supports numbers and special characters
- Allows custom password length
- Minimum length of 8 characters

## Technologies Used

- Python 3
- `random` module
- `string` module

## How to Run

```bash
python password_generator.py
```

## Example

```text
Enter password length: 12
Password: a#7K!p2@Lm9$
```
